我为什么要有一个自己的网站

随笔

今天我把这个站点上线了。它很朴素：几个静态页面，一段样式表，托管在 GitHub Pages 上，一年花不了几块钱——准确说是零。

平台的问题不是审查，是所有权

我在社交平台上写的东西，链接会失效，账号可能被限制，格式会被改版吞掉。最要命的是：内容存在别人的数据库里，排序由别人的算法决定，我连导出都得挑个能用的工具。

平台是租来的房子，装修得再好，房东一句「规则调整」你就得搬。

自己的站点不一样。文件在我的硬盘上，Git 里留着每一次修改，哪怕哪天 GitHub 不干了，我可以把整个目录拷到任何一台服务器上，十分钟重新上线。这种「随时能走」的自由，是我最想要的东西。

写下来才会想清楚

有个说法是：你以为自己懂了，直到你试着写给别人看。我确实在写这篇文章的时候，才发现自己对「静态站点」的理解有几个含糊的地方——于是去查了资料，补上了。

写作是思考的慢速回放。

为什么是 GitHub Pages

  • 免费，公开仓库就行，不用备案、不用买服务器
  • 简单，没有后端，没有数据库，坏不了
  • 和我已有的工作流一致，代码本来就放在 GitHub
  • 可迁移，纯静态文件，搬到哪都能用

代价是它只能放静态内容，评论要靠第三方服务，动态功能基本没有。但对我需要的「写点东西」来说，完全够了。

下一步

我打算先保持这个简单的样子，用几个月看看自己到底会不会持续写。如果写了半年还有话说，再考虑买域名、加评论。

在那之前，任何工具都是在给「开始」找借口。
